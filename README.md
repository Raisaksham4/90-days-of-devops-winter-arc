# 90-Day DevOps Winter Arc

This repository documents my 90-day journey to strengthen my DevOps skills
through consistent learning, hands-on implementation, troubleshooting, and
interview preparation.

The goal is to turn concepts into working projects that I can explain clearly,
including the decisions, failures, fixes, and trade-offs behind them.

## Journey Structure

Each day has its own folder containing the practical work completed that day.

```text
90-days-of-devops-winter-arc/
|-- Day-01/
|-- Day-02/
|-- Day-03/
|-- ...
`-- Day-90/
```

Folders are created as the challenge progresses. Every daily folder may include:

- A daily README with objectives and learnings
- Scripts and configuration files
- Commands and implementation notes
- Troubleshooting records
- Project documentation and evidence

## Working Principles

1. Learn the concept.
2. Implement it locally.
3. Test and troubleshoot it.
4. Document the result.
5. Explain what worked, what failed, and why.
